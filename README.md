# Roster

A simple static rostering web app. No database: everything stays in the browser, and you export / import a data file between rostering rounds.

Open it at https://linnzawwin.github.io/Roster/

- **Roster**: generate a roster, click any cell to change it, see hours per fortnight, export to Excel or print.
- **Staff**: FTE, which shifts each person can work on which days, alternate weeks, grouping shifts together.
- **Shifts**: shift times, paid hours, colours and how many staff each day needs.
- **Requests**: days off, leave or a set shift for one person.
- **Settings**: roster period, rules, export / import of the data file.
